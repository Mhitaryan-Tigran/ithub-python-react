# Защита TaskFlow (3–5 минут)

## 1. Что это (20 секунд)
TaskFlow — командная доска задач в реальном времени. Всё, что делает один участник, сразу видят остальные: новые задачи, перенос между колонками, обложки, сообщения в чате.

## 2. Демо в двух окнах (2 минуты)
1. Окно 1 — войти как «Анна», окно 2 — как «Борис». В шапке видно, кто онлайн.
2. Анна создаёт задачу и назначает её Борису → у Бориса задача появляется сама, плюс всплывает **личное** уведомление (его видит только Борис).
3. Борис перетаскивает карточку в «В процессе» → у Анны она переезжает без перезагрузки.
4. Анна открывает задачу, загружает обложку → Pillow обрезает её до 640×360, у Бориса обложка появляется на доске.
5. Чат: обмен сообщениями. Вкладка «Активность»: лента событий и статистика.

## 3. Архитектура (1–1,5 минуты)
- **Backend на FastAPI** по структуре курса: `main.py`, `config.py`, `models/`, `routers/`. CORS берёт адрес фронта из `.env`.
- **Почему WebSocket, а не SSE:** связь нужна в обе стороны (чат идёт от клиента к серверу), а событий много и разных. SSE передаёт данные только от сервера к клиенту.
- **Изменения идут через REST, рассылка через WebSocket.** POST, PATCH и DELETE проходят валидацию Pydantic и возвращают понятные ошибки, а после изменения `publish()` рассылает событие всем. Так ошибки не теряются в сокете.
- **ConnectionManager** хранит список сокетов на каждого пользователя: один человек может держать несколько вкладок. `broadcast` рассылает всем, `send_personal` — только назначенному исполнителю.
- **При подключении** сервер присылает `snapshot`: все задачи, ленту и чат. Новая вкладка сразу видит актуальное состояние.
- **React:** один сокет живёт в контексте `LiveBoardProvider`, страницы читают из него через `useLiveBoard()`. При обрыве связи клиент переподключается через 2 секунды.
- **Pillow:** проверка типа и размера (до 5 МБ, иначе 400), `ImageOps.fit` до 640×360, раздача через `StaticFiles` по полному URL.

## 4. Возможные вопросы
| Вопрос | Ответ |
|---|---|
| Почему кириллица в имени не ломает заголовок? | HTTP-заголовки только latin-1, поэтому `X-User` кодируется через `encodeURIComponent` и декодируется на сервере в `deps.py`. |
| Где хранятся данные? | В памяти процесса — для демо. Хранилище вынесено в `store.py`, поэтому замена на базу данных затронет только его. |
| Что будет, если сервер упадёт? | Индикатор станет красным («переподключаемся…»), клиент будет пытаться подключиться снова, а после подключения получит `snapshot`. |
| Как проверить без браузера? | `pytest -q test_api.py`: тест подключает двух пользователей по WebSocket и проверяет рассылку, личное уведомление, перенос задачи, обложку и чат. |
